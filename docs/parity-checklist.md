## Not implemented yet

### Connection

- MongoDB connection (`conn.mongodb`) — catalogued, no driver yet
- Redis connection (`conn.redis`) — catalogued, no driver yet
- SQL Server connection (`conn.sqlserver`) — catalogued, no driver yet
- Oracle connection (`conn.oracle`) — catalogued, no driver yet
- HTTP tunnel (`conn.httpTunnel`) — not implemented; use SSH
- Cloud database connections (`conn.cloud`) — not implemented; connect over a tunnel instead
- PAM authentication (`conn.pamAuth`) — not implemented; the drivers offer password auth only
- LDAP authentication (`conn.ldapAuth`) — not implemented; the drivers offer password auth only
- Kerberos authentication (`conn.kerberosAuth`) — not implemented; the drivers offer password auth only
- Export and import connection settings (`conn.settingsFile`) — not implemented; profiles.json is copied by hand. Job profiles already export and import
- Pub/Sub (`conn.pubsub`) — not implemented; needs a Redis or MongoDB driver first

### Query

- Stored procedure debugger (`sql.debugger`) — not implemented
- Refactoring (`sql.refactor`) — not implemented; rename and drop are on the design toolbar, not in the editor
- Find builder (`sql.findBuilder`) — not implemented; the grid filter takes a WHERE clause by hand
- Aggregate builder (`sql.aggregateBuilder`) — not implemented; report.aggregate and report.pivot are the closest surface
- Console (`sql.console`) — the message log (app.log) and the control channel; no REPL pane
- Pin query result (`sql.pinnedResult`) — not implemented; a result lives in its tab until the tab closes

### Tools

- Auto-update (`tools.updater`) — not implemented; builds are local
- Schema analysis (`tools.schemaAnalysis`) — not implemented; the structure diff is the closest surface

### Cloud

- Team collaboration (`cloud.team`) — not implemented
- Cloud-synced settings (`cloud.syncSettings`) — settings are JSON on this machine
- Shared query library (`cloud.sharedQueries`) — snippets are local to this machine

### Platform

- Browser build (`platform.web`) — not implemented; this is a native tool

### Data

- Data masking (`data.masking`) — not implemented; the generator can fake a column, not mask an existing one
- Customize data type colourings (`data.typeColors`) — not implemented; the grid paints one colour for every type

### Import/Export

- Import Parquet (`tools.importParquet`) — not implemented; needs a Parquet reader crate
- Export to Parquet (`tools.exportParquet`) — not implemented; needs a Parquet writer crate
- Import from ODBC (`tools.importOdbc`) — not implemented; the drivers speak their own wire protocols, not ODBC
- Import from MS Access (`tools.importAccess`) — not implemented; .accdb is not a format any current driver reads
- Export to MS Access (`tools.exportAccess`) — not implemented; .accdb is not a format any current driver writes
- Export to DBF (`tools.exportDbf`) — not implemented; the reader landed, the writer has not

### Monitor

- Command monitor (`monitor.commandLog`) — monitor.processes lists live statements; there is no server-side history view

### Modeler

- Print a diagram to PDF (`diagram.exportPdf`) — not implemented; the export writes SVG only
